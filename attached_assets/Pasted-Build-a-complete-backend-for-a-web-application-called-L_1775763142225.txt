Build a complete backend for a web application called:

"LLM-Powered Log Forensic Investigator"

The backend must be fully functional and designed to integrate with an existing frontend dashboard hosted on Replit.

Tech Stack:

* Python
* FastAPI
* MongoDB Atlas (cloud database using pymongo)
* Gemini API (for LLM-based analysis)

---

CORE REQUIREMENTS:

1. Setup FastAPI server

* Enable CORS (allow all origins for development)
* Run on 0.0.0.0 and dynamic port (Replit compatible)

---

2. Database (MongoDB Atlas)

Create collections:

* logs
* alerts
* sessions

Each log should be stored in structured JSON format:
{
timestamp,
ip,
event,
status,
risk
}

---

3. Log Upload API

POST /upload

* Accept .txt, .log, .csv files
* Read and split logs line-by-line
* Parse logs into structured format
* Store in MongoDB
* Return success response

---

4. Log Parsing Module

Extract from each log:

* IP address
* timestamp
* event type (login, access, error)
* status (success/failed)

Use regex where needed

---

5. Detection Engine

Implement rule-based detection:

* Brute Force Attack:
  More than 5 failed logins from same IP → HIGH risk

* Suspicious Access:
  Access to /admin or sensitive files

* Unusual Activity:
  Activity at odd hours

* Sequence Detection:
  Failed → Failed → Success → possible compromise

Store alerts in MongoDB with:
{
type,
ip,
risk,
timestamp
}

---

6. Alerts API

GET /alerts

* Return all detected threats
* Include risk level and details

---

7. Logs API

GET /logs

* Return recent logs
* Limit to latest 100 entries

---

8. LLM Integration (Gemini API)

POST /analyze

* Input: detected alert or log event
* Send only important event data to LLM

Prompt:
"You are a cybersecurity expert. Analyze the following event:

1. Identify attack type
2. Explain why it is dangerous
3. Suggest mitigation steps"

Return:

* explanation
* risk level
* recommended actions

---

9. AI Incident Investigator (Advanced Feature)

POST /investigate

* Analyze sequence of logs
* Detect attack flow
* Identify root cause
* Return structured explanation

---

10. Live Monitoring (Simulated)

GET /live-logs

* Stream logs or simulate new logs every few seconds
* Return latest generated logs

---

11. Session / History API

POST /session

* Save analysis session

GET /sessions

* Return previous sessions

---

12. Export API

GET /export

* Export logs or alerts as:

  * JSON
  * CSV

---

13. Code Structure

* main.py (FastAPI app)
* parser.py (log parsing)
* detector.py (rule engine)
* database.py (MongoDB connection)
* llm.py (Gemini integration)

---

14. Error Handling

* Handle invalid files
* Handle empty logs
* Return proper JSON responses

---

15. Output Format

All APIs must return clean JSON responses

---

GOAL:

The backend must:

* Fully support all frontend features
* Work smoothly on Replit
* Be modular and clean
* Be demo-ready for a hackathon
* Simulate real cybersecurity analysis

Tone:

* Professional
* Clean code
* Production-like structure
